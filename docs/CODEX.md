# Передача задач Codex через GitHub

Claude Code ставит задачу Codex сам: пишет в GitHub Issue комментарий с упоминанием `@codex`.
Codex работает в облаке ChatGPT по подписке PM. API-ключи не нужны, терминал не нужен.

## Почему так, а не Codex внутри сессии Claude

| Способ | Вход | Переживает перезапуск | Терминал PM |
|---|---|---|---|
| **`@codex` в GitHub (выбран)** | аккаунт ChatGPT, один раз в браузере | да | не нужен |
| Codex CLI в облачной сессии Claude | код входа заново почти в каждой сессии, токены лежат во временной машине | нет | не нужен, но вход регулярный |

## Разовая настройка — делает PM в браузере или приложении ChatGPT

1. **Включить Codex.** Открыть chatgpt.com/codex и войти своим аккаунтом ChatGPT.
   Это сама «рабочая комната» Codex. Там будут видны его задачи.
2. **Подключить GitHub.** В Codex нажать «Connect GitHub» (или ChatGPT → Настройки → Connectors → GitHub) и разрешить доступ
   к репозиторию `prostovasei/simpe-tasks-app`.
   Так Codex сможет читать код, создавать ветки и PR. Доступ только к выбранным репозиториям.
3. **Создать окружение.** В Codex → Environments → «Create environment» выбрать этот репозиторий, настройки по умолчанию.
   Это облачная машина, где Codex работает с кодом. Android-сборку он может не потянуть — тогда проверку делает Android CI в PR (см. AGENTS.md).
4. **Проверка связи.** Сказать Claude «проверь Codex». Claude напишет в тестовом Issue `@codex` и посмотрит, ответил ли Codex.
   Если Codex ответил «connect your account», значит, шаг 2 не завершён.

## Как Claude передаёт задачу

1. Задача — отдельный GitHub Issue: ожидаемое поведение, критерии готовности, ссылки на макеты.
   Исполнитель: Codex, статус «В работе». В [HANDOFF](HANDOFF.md) записывается, что фича у Codex.
2. Claude пишет в Issue комментарий по шаблону:

   ```
   @codex Выполни этот Issue целиком.
   Сначала прочитай AGENTS.md и docs/HANDOFF.md. Начни новую ветку от свежего main.
   Результат — PR с описанием по шаблону, ссылкой на этот Issue и обновлённым docs/HANDOFF.md.
   ```

3. Codex отвечает в Issue и работает в облаке. Результат — ветка и PR.
   Если Codex предлагает кнопку «Create PR» в своём интерфейсе, нажимает PM. Точное поведение уточняем на первой задаче.
4. Пока задача у Codex, Claude эту фичу не трогает (правило AGENTS.md: одна фича — один инструмент).
5. Когда PR готов, Claude проверяет Android CI и соответствие Issue. Правки просит у Codex комментарием `@codex …` в PR. Merge — по правилам AGENTS.md.

## Проверка связи — 10.11.2026, Issue #219

- Без окружения Codex отвечает «create an environment for this repo» — нужен шаг 3.
- С окружением: реакция 👀 через несколько секунд, ответ комментарием через ~4 минуты, со ссылкой «View task» на задачу в ChatGPT.
- Ответ верный: прочитал AGENTS.md и docs/HANDOFF.md, ничего не изменил. Создание PR по задаче ещё не проверялось.

## Ограничения

- Упоминание `@codex` срабатывает только после шагов 1–2. До этого Claude не может ставить задачи Codex.
- Лимиты Codex зависят от тарифа ChatGPT. При исчерпании Codex откажет в Issue — Claude сообщит PM.
- Codex не видит чат Claude. Всё нужное должно быть в Issue и файлах репозитория.
