## Порядок для Claude с доступом к артефактам

1. Прочитать полностью коллекцию `items`; сохранить исходные ID и все поля:
   `c, e, i, r, num, iteration, section, source, status, title, why, createdAt, updatedAt`.
   Экспорт — `docs/imports/claude-backlog.json`; служебные токены и личные задачи пользователя не включать.
2. Перед созданием Issue искать T-N среди открытых и закрытых Issues. Не путать T-N с GitHub #N.
   Заголовок: `[T-N] исходное название`; тело: описание, исходный статус, версия, источник, все значимые поля.
3. Отобразить статусы: backlog → открыта/«Бэклог», progress → открыта/«В работе»,
   paused → открыта/«Приостановлен», done → закрыта/«Готово».
   Время исторических событий сохранить текстом/в JSON: дата создания GitHub Issue будет новой.
4. Заполнить ниже таблицу T-N → Issue; сверить количество, уникальность номеров и распределение статусов.
5. Экспортировать точные формулировки и ID чек-листа и коллекцию `runs`; сохранить в `docs/imports/`.
   Результаты прогонов отдельно от требований. Объединить с [TESTING.md](TESTING.md), не заменяя исходную историю новой smoke-проверкой.
6. Сверить опубликованные утверждённые макеты с [design/README.md](../design/README.md), сохранить отсутствующие материалы.
7. После проверки отметить прежние артефакты архивными, закрыть #92, обновить HANDOFF и этот статус.
