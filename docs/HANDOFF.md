## Важные ограничения

- PM в основном использует виджет и уведомления. Вибрацию не добавлять.
- Установленные данные сохраняются через миграции Room; реальные CSV PM не коммитятся.
- Codex не видит приватные Claude Artifacts — всё нужное уже в репозитории и Issues (см. BACKLOG-MIGRATION.md).
- Задачи — только GitHub Issues. Старые T-N не перенумеровывать; не вести две редактируемые копии одной карточки.
- Облачная сессия Claude Code пушит только в выданную ей ветку (сейчас `ccr-899ee205-ffqd23`), пересоздавая её от свежего main на каждую задачу.
- Настройки SDK/зеркал зависят от среды; см. AGENTS.md. APK публикуется CI в simple-tasks-releases.
