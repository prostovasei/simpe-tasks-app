## Этап «Проверка»

- Найдено при вычитке и исправлено: перед каждым перезапуском вызывался `cancel()`, даже если прошлая запись уже завершилась. Часть движков отвечает на такой `cancel()` запоздалым `ERROR_CLIENT`, который попадал бы в новый запуск и вызывал лишний тихий повтор (+0,5 с к старту). Теперь `cancel()` — только для незавершённой записи.
- Проверены по коду: «Отмена» и «Готово» во время ожидания повтора отменяют его (номер запуска меняется); журнал пишется только при ошибках, файл до 300 строк; текст речи в журнал не попадает — только код.
- Финальный `./gradlew assembleDebug check recordRoborazziDebug` — успешно: 929 тестов, 0 ошибок, 3 пропуска. Снимки окна голосового ввода не изменились. APK 0.82.2 (локальный versionCode 214 занижен из-за неполной истории клона).
