# Макеты #280 на согласование

[Приложение](app.png) показывает компактную группу из четырёх иконок и полноэкранные «Настройки». [Виджет](widget.png) показывает три состояния при 320 dp и «Здоровье» при 180×110 dp.

На широком размере «+» занимает 64 dp, шаг вкладок — 40 dp. Дата с крупным числом и двумя строками стоит перед обновлением у правого края. На компактном размере «+» занимает 48 dp, каждая вкладка — 40 dp. Даты и обновление скрыты. В приложении шаг вкладок — 48 dp.

Содержимое экранов иллюстрирует расположение элементов. Для компактного графика используется снимок 0.79.3, иконки взяты из ресурсов приложения. Воспроизведение из корня репозитория:

```sh
python3 design/drafts/compact-tabs-widget-date/screens.py
node design/drafts/compact-tabs-widget-date/render.js
```

Для рендера нужны Playwright и Chromium. Проверки рендера сравнивают координаты кнопок во всех модулях, размеры зон, высоту цифр и двух строк даты, наличие действия даты только в «Задачах» и скрытие панели в «Настройках».
