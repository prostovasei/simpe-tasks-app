# ТЗ — компактные вкладки, дата виджета и полноэкранные «Настройки»

Исполнитель — Codex. База — 0.79.3, build-406, PR #279. Решения по компактному виджету и нажатию на дату подтверждены 21.11.2026.

## Приложение

- Сократить расстояние между четырьмя иконками нижней панели. Вкладки собраны в компактную группу, у каждой своя зона нажатия. На обычной ширине ориентир — шаг иконок 48 dp. Кнопка «+» слева.
- Иконка «Настройки» открывает отдельный экран на всю область приложения. На главной странице настроек и в её подразделах нижняя панель приложения скрыта.
- Стрелка назад и системное действие «Назад» из подраздела ведут на главную страницу настроек. Выход с главной страницы возвращает в модуль, из которого открыли настройки, с его выбранным разделом и восстановленной панелью.

## Широкий виджет

- Слева «+» шириной около 64 dp. Три кнопки «Задачи», «Финансы» и «Здоровье» образуют компактную группу в геометрическом центре, ориентир по расстоянию между центрами — 40 dp. Координаты кнопок фиксированы для всех модулей при одном размере виджета.
- Справа от вкладок текущая дата, затем иконка обновления у правого края. Дата во всех модулях в одном формате и на одном месте. Пример — крупное «21» слева, справа «СБ» над «ноя». Видимая высота цифр равна высоте двух строк вместе с промежутком. Число и подписи выровнены по вертикали.
- В «Задачах» нажатие на дату возвращает к текущему дню. В «Финансах» и «Здоровье» дата — информационная подпись. Обновление открывается по своей иконке.
- Размер 320 dp — контрольный для полного ряда. При нехватке ширины используется компактная раскладка. Проверить читаемость двухзначного числа, дня недели и месяца при увеличенном шрифте.

## Компактный виджет

- Слева расширенный «+», справа три сближенные вкладки. Дата и обновление скрыты. Иконки остаются в одних координатах при переключении.
- На 180×110 dp ориентир — 48 dp для «+» и по 40 dp для вкладок. Боковые поля по 6 dp. Нажатия на соседние кнопки разделены.

## Приёмка

1. На телефоне сверить расстояние между иконками приложения. Открыть «Настройки» из каждого модуля, перейти в подраздел, вернуться стрелкой и системным «Назад». Проверить скрытие панели и возврат в открытый ранее модуль.
2. На широком виджете переключить все три вкладки. Проверить неподвижность иконок, широкий «+», один формат даты, высоту цифр относительно двух строк и обновление справа.
3. В прошлой неделе нажать дату и вернуться к текущей. В «Финансах» и «Здоровье» нажатие даты не открывает действие и не меняет неделю задач.
4. На 180×110 dp сверить «+» и три вкладки, проверить зоны нажатия и отсутствие даты и обновления. Увеличить ширину до полного ряда и повторить проверку.

Макеты готовятся в `screens.py` и `render.js` и согласуются отдельно. Для реализации нужна команда «Делай код».
