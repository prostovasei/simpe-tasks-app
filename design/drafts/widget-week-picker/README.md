# Мини-календарь виджета на согласование (#284)

[Три прототипа PNG](variants.png) · [Интерактивное превью](screens.html) · [Задача #284](https://github.com/prostovasei/simpe-tasks-app/issues/284)

Во всех вариантах шесть строк по семь дат. Обычные даты набраны обычным шрифтом, 21 ноября — жирным. Даты соседних месяцев светлее. Круг и подписи дней недели убраны из мини-календаря. Высота равномерно распределена между шестью строками, нажатие на любую часть строки подсвечивает неделю. Жирное начертание остаётся у сегодняшней даты при выборе другой недели.

1. Светлая полоса на всю выбранную неделю.
2. Тонкая рамка вокруг выбранной недели.
3. Вертикальная метка слева от выбранной недели.

Соседняя ячейка воскресенья иллюстрирует положение календаря по скриншоту PM. В интерактивном превью можно сменить выбранную строку. Проверены веса шрифта, сетка и смена выбранной строки на ширине 392 и 320 dp.

```sh
python3 design/drafts/widget-week-picker/screens.py
node design/drafts/widget-week-picker/render.js
```

Для рендера нужны Playwright и Chromium. PM выбрал вариант 1. [Утверждённый макет и ТЗ](../../approved/284/requirements.md).
