# Окно задачи поверх окна дня — черновик (1 + 2)

Статус — на согласовании PM (24.11.2026). Замечание PM по видео: при создании задачи из окна дня окно «дёргается, появляется и исчезает». Разбор: окно дня исчезает без анимации, затемнение мигает, окно задачи выезжает снизу и подпрыгивает с клавиатурой, при возврате окно дня «выскакивает». PM выбрал направление «1 + 2»: окно задачи поверх окна дня + «+» превращается в окно задачи (идея 9 из #314).

- [screens.html](screens.html) — живой макет: «+» вырастает в окно новой задачи, задача — из своей строки; окно встаёт сразу над клавиатурой и поднимается вместе с ней; «Назад» — сжимается обратно. Три варианта окна дня под окном задачи: 1 остаётся на месте, 2 отступает вглубь, 3 поднимается выше.
