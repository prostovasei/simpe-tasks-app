## Почему панель выглядит неровно

Значки «+», вкладок и обновления выводятся в контейнерах 22×22 dp. Рисунки внутри исходных файлов отличаются по высоте, ширине и толщине линии. Например, видимый «+» около 13 dp, рамка недели около 15 dp по высоте, знак рубля около 17 dp. Число даты в APK выводится шрифтом 26 sp, а «СБ» и «ноя» отдельными строками по 9 sp и с разным начертанием. Android центрирует текстовые блоки, поэтому их видимые границы могут расходиться.

В широком ряду build-411 нажимается полоса шириной 30 dp сразу после «+». Два отступа, которые расширяются вместе с виджетом, действия не получают. При 320 dp правый промежуток отсутствует, потому что дата начинается сразу за блоком вкладок. В компактном ряду действие открытия приложения назначено родительской панели.

## Общее решение

- Ориентир по видимой высоте всех значков — 16 dp. Толщина штриха единая, у каждого рисунка сохраняются пропорции. Области нажатия имеют отдельные размеры. Активная вкладка чёрная, остальные серые.
- Для даты используется одно семейство шрифта и общий вертикальный центр. Высота видимых цифр соответствует высоте двух строк «СБ» и «ноя». День выводится табличными цифрами. При увеличении системного шрифта проверить читаемость и при необходимости переключиться на компактную раскладку.
- На широком виджете только два непрерывных промежутка открывают приложение. Левый покрывает всю свободную полосу между «+» и блоком вкладок, правый — между блоком вкладок и датой. Схема показывает их голубым для проверки.
- Дата в «Задачах» возвращает к сегодня. В «Финансах» и «Здоровье» она информационная. У «+», трёх вкладок и обновления свои действия. Вкладки центрированы на широком размере и остаются на месте при переключении модуля.

## Варианты

| Вариант | Отличие | Шаг вкладок | Промежутки на 320 dp, слева / справа | На 392 dp |
|---|---|---:|---:|---:|
| 1. Сплошная панель | Единый белый фон | 36 dp | 36 / 16 dp | 72 / 52 dp |
| 2. Тонкие разделители | Вертикальные линии обозначают границы группы | 34 dp | 39 / 21 dp | 75 / 57 dp |
| 3. Общая подложка | Три вкладки на одной светлой подложке | 32 dp | 42 / 28 dp | 78 / 64 dp |

«+» на широком размере сохраняет ширину 64 dp. Более плотная группа освобождает место справа при 320 dp, при этом ширина зон самих вкладок уменьшается. При 392 dp обе зоны открытия приложения широкие во всех вариантах.

На 180×110 dp «+» и три вкладки занимают всю доступную ширину. Зон открытия приложения в этом ряду нет. На промежуточной компактной ширине левая зона занимает свободное место между кнопкой «+» и компактной группой вкладок. Правую зону добавляет полная панель с датой.

## Проверка и воспроизведение

В Playwright проверены размеры и геометрия при 180, 240, 320 и 392 dp, одинаковый центр вкладок, видимая высота значков, клики в двух зонах и отдельные действия кнопок. Превью показывает реакцию на нажатие, которую затем нужно проверить на Android по координатам и на реальном рабочем столе. Отдельно сверить вариант «Все» и «Входящие» и крупный системный шрифт.

```sh
python3 design/drafts/widget-bar-consistency/screens.py
node design/drafts/widget-bar-consistency/render.js
```
