# Финансы — макеты на согласовании (#217)

Статус: черновик. Выбрана общая навигация А; основные экраны и формы ещё ожидают согласования PM.
[Требования](requirements.md) — сводка ответов из чата, не описание уже работающего Android-раздела.

## Просмотр

- [Основные экраны](main-screens.png): аналитика, компактная история, счета.
- [Формы](operation-forms.png): расход, состояние с условной клавиатурой, перевод.
- [HTML-прототип](finance-screens.html): скачать и открыть в браузере. Шрифт встроен, сетевых запросов нет.
  Дополнительно доступны доход, новый счёт и первый запуск.
- Суммы и операции условные. Прототип не является реализацией финансового учёта и не хранит реальные деньги.
  Сохранение показывает поведение формы; остатки/аналитика остаются демонстрационными.
  Черновик живёт только в памяти открытого HTML-прототипа. Полноценное устойчивое хранение будет в Android.
- Служебные пункты открываются через шестерёнку. Их размещение — предложение для PM; служебные экраны будут отдельным этапом.
- При сохранении редактируемой операции прототип закрывает окно. Это предложение, а не дополнительное принятое решение.
- Клавиатура на изображении условная. В Android дополнительно проверяется реальная системная клавиатура.

## Воспроизведение

Из корня репозитория:
```sh
python3 design/drafts/finance-217/screens.py
python3 design/drafts/finance-217/render-screens.py
```

Генератор берёт Manrope из app/src/main/res/font. Для скриншотов нужны Python Playwright и Chromium
(путь /usr/bin/chromium можно адаптировать к среде). Макеты используют палитру ColorTokens и шкалу размеров DimensionTokens;
это HTML-адаптация, а не новые Kotlin-токены.

Проверено в браузере: вкладки, открытие операции, возврат к черновику, последовательный ввод после сохранения,
проверка разных счетов перевода, доступность «Сохранить» над клавиатурой, отсутствие горизонтального переполнения при ширине 360.
Девять состояний просмотрены; изображения сгенерированы при размере 390×844. Ошибок JavaScript нет.
