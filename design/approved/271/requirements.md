# ТЗ #271 — доли расходов и компактные счета

Исполнитель Codex. Статус — в работе, ТЗ и макет виджета согласованы, PM дал «Делай код». База — 0.77.0, PR #270, build-390. Реализация начинается после команды «Делай код». [Issue #271](https://github.com/prostovasei/simpe-tasks-app/issues/271) · [Макеты](README.md).

## Доли расходов

- В приложении и во вкладке «Финансы» виджета вместо таблиц две горизонтальные полосы на всю ширину, одна под другой. Первая показывает категории, вторая — места. Видимые заголовки убрать. Названия групп доступны для чтения с экрана.
- В каждой группе взять четыре позиции с наибольшим расходом. Остальные собрать в «Остальное», включая расходы без места в рейтинге мест. Показанные позиции, включая «Остальное», упорядочить по убыванию точной суммы. При равенстве сортировать по названию и использовать стабильный ключ при одинаковых названиях.
- Обе полосы и чипы используют одну палитру из пяти цветов в порядке ранга — фиолетовый, синий, бирюзовый, янтарный, серо-синий. Позиция после сортировки определяет цвет. Использовать общие токены из [макета](finance-app.html), с заливкой чипа 10% цвета сегмента на белом фоне.
- Ширина сегмента пропорциональна точной доле расходов за выбранный месяц. Скруглить оба конца каждого сегмента. Над сегментом вывести целый процент у его левого края.
- Для расчёта подписей взять целые части точных процентов и раздать недостающие до 100 пункты по одному позициям с наибольшими дробными остатками. При равных остатках приоритет у более ранней позиции в готовой полосе. В макете доли составляют 44%, 22%, 15%, 12%, 7% для категорий и 31%, 24%, 19%, 15%, 11% для мест.
- Под каждой полосой пять ячеек, каждая занимает 20% ширины. В чипе слабая заливка цвета сегмента и максимальное скругление. Название сверху, сумма более мелким шрифтом снизу. Обе строки выровнены влево. Название обрезается по ширине чипа без многоточия. Полное название и точная сумма доступны для чтения с экрана.
- Чипы показывают целые тысячи без знака рубля, например `4k`. Округление выполняется из исходной суммы в копейках за один шаг. Размер названий уменьшен по макету. Суммы в чипах и проценты округляются независимо.

## Счета и экран

- Над счетами вывести общий баланс из точных балансов всех счетов в формате `128k ₽`. Заголовок «Счета» убрать. На экране приложения сохранить кнопку добавления счёта рядом с балансом и открытие счёта при нажатии на его чип.
- Счета показывать в существующем порядке. Чип светло-серый, максимально скруглённый. Слева иконка, справа компактная сумма в том же формате `4k`. Название доступно для чтения с экрана.
- В ряду максимум четыре счёта. Следующие счета переносятся на следующую строку. Число колонок уменьшается по доступной ширине, чтобы целиком поместились иконка и сумма.
- На экране приложения обе стрелки рядом с месяцем `ноя 26` одного серого цвета. Переход между месяцами работает по существующим правилам. Сразу после аналитики идёт лента с заголовками дат, без отдельного заголовка «Операции».

## Виджет

- График и суммы, две полосы с чипами и все счета доступны в одной вертикальной прокрутке. Внизу закреплена текущая панель виджета с вкладками и «+». На размере 180×110 dp все чипы достижимы прокруткой, а пять позиций каждой полосы помещаются в одну строку по ширине.
- Один расчёт для приложения и виджета. При просмотре текущего месяца цвета, порядок, суммы и проценты совпадают. Изменения операций, счетов и лимита, а также переход на новый месяц отражаются в виджете.
- Рабочее допущение для согласования — в виджете по-прежнему текущий месяц и порядок блоков из #269 (график и суммы, доли, счета). Стрелки и лента операций относятся к экрану приложения.

## Правила для граничных случаев

- При расходах в одной позиции она занимает 100% полосы и получает первый цвет. При числе позиций меньше пяти ячейки сохраняют ширину в 20%. Показать только фактические позиции. Пустой месяц сохраняет существующее состояние без полос долей. Положительная доля может округлиться до 0%.
- При касании подписей процентов разнести их по высоте над полосой. Если подпись у правого края выходит за доступную ширину, сдвинуть её внутрь на минимальное расстояние. Это рабочее допущение для компактного виджета, геометрия сегментов рассчитывается из точных долей.
- Рабочее допущение для формата — половина тысячи округляется от нуля, суммы меньше 500 ₽ по модулю показываются как `0k`. Точная сумма доступна для чтения с экрана и при просмотре данных в приложении. Знак минуса сохраняется у отрицательной округлённой суммы, отличной от нуля.

## Критерии приёмки

- [ ] В текущем месяце сверить приложение и виджет на одинаковых данных. В каждой непустой полосе целые подписи дают ровно 100%, ширина сегментов отвечает точным расходам, один ранг получает один цвет на обеих полосах.
- [ ] Проверить пять позиций, одну позицию, пустой месяц, близкие и очень малые доли, расходы без места и случай, когда «Остальное» выходит на первое место. Изменить расход и сверить повторную сортировку и обновление виджета.
- [ ] Проверить левое выравнивание, округлённые суммы, скругления, одинаковые стрелки месяца и ленту приложения. На длинном названии проверить обрезку без многоточия и полное озвучивание.
- [ ] Создать больше четырёх счетов, включая счёт с отрицательным балансом. Сверить общий баланс и перенос чипов. На минимальном виджете прокрутить до последнего счёта. Проверить на Android 10–11, Android 12+ и в Nova Launcher, включая увеличенный шрифт.
- [ ] Сменить месяц в приложении и сверить данные. Проверить обновление виджета после смены месяца, закреплённую нижнюю панель, переключение вкладок и «+».
