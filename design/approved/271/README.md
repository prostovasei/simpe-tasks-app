# #271 — доли расходов и компактные счета

20.11.2026. Исполнитель Codex. ТЗ и макет виджета согласованы, PM дал «Делай код». [Условия и приёмка](requirements.md) · [Issue #271](https://github.com/prostovasei/simpe-tasks-app/issues/271).

- [Приложение, 360 dp](finance-app.png) · [Исходный HTML](finance-app.html). Последний вариант из обсуждения. Пять скруглённых чипов под каждой полосой, четыре счёта в ряду, целые доли и суммы.
- [Финансовый виджет](widget-finance.png). Широкий вид и компактная прокрутка. График и суммы идут первыми, за ними обе полосы и счета.

Значения на макетах вымышлены. Общий баланс составляет 128 450 ₽, расходы месяца — 28 400 ₽.

Для воспроизведения из корня репозитория выполнить `node design/approved/271/render.js` для приложения и `python3 design/approved/271/widget-screens.py` для виджета. Рендеры используют Chromium и Playwright. Приложению также нужны SVG-иконки Lucide, виджет берёт иконки из ресурсов проекта.
