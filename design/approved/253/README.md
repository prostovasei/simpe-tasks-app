# #253 — согласованные зазоры и иконки недели, 0.70.2

После отдельного согласования макетов PM дал явную команду **«Делай код»**. Это разрешение именно на перечисленные изменения, не на новый дизайн всего приложения.

- [Направление недели](week-direction.png): одинаковые значки, +N без плашки. На этом раннем эскизе 2 dp — отменены следующим решением.
- [Последний согласованный фрагмент](spacing-1dp.png): **время — 1 dp — значок — 1 dp — название**, и приложение, и виджет. День и время на общей левой линии. Нет прежней колонки 34 dp и внутренних горизонтальных полей значка. Колонка по HH:mm с tabular digits, пустая без времени.
- Круг 14 dp, обводка 1.5 dp; общий ресурс круга/заливки, галочки и повтора для обоих рендереров. +N обычным текстом, без фона, рамки, тени.
- Цвета/бледность выполненных/эмодзи и отсутствие зачёркивания из 0.70.1 сохраняются. Фон #FFFFFF, сетка/высоты/календарь/порядок/действия/данные прежние.

Генеративные эскизы показывают согласованные изменения и не гарантируют пиксельную точность: случайные отличия navbar/подписей/дат/цвета активной задачи на них не являются требованиями. Android-снимки в [screens.html](screens.html) показывают фактическую реализацию. Источник досок — approved/241/251. Запуск: `python3 design/approved/253/screens.py` и `node design/approved/253/render.js` после записи Roborazzi.
