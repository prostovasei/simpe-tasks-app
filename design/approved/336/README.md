# #336 — хаб и навбар

25.11.2026, Claude Code. Запрос PM (референс — плавающая панель Samsung Health): новости над задачами, навбар из трёх кнопок
(«+», хаб, настройки) плавающий справа, новые значки хаба и настроек, круглый «+», выбор вкладки по нажатию на хаб, виджет — так же,
другие варианты листания новостей в виджете, средняя сумма в день, крупнее плашки счетов, хаб в приложении и виджете — одинаковый.

Статус: **конструктор, ждёт выбора PM**.

- [Конструктор](constructor.html) ([артефакт](https://claude.ai/artifact/UmhQGo3fPpT98FmNTXtPi9)): приложение и виджет рядом, переключатели навбара,
  значков, выбора вкладки, блоков хаба и листания новостей в виджете; «Скопировать выбор» даёт текст для чата.
- Рекомендации: капсула [хаб · настройки] + чёрный круг «+» справа, кнопки 44 dp, белая с тенью; значки «плитки» и «ползунки»;
  выбор вкладки — меню над кнопкой, «Предстоящее», «Неделя», «Списки» отдельно; средняя сумма — обе («в среднем» и «можно в день») в строке под полосой;
  счета — плитки с названием; в виджете — стопка новостей со свайпом.
