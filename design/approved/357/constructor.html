Сортировка задач

Живой макет по твоим ответам (#357). Справа экран приложения: кнопка ↑↓ в капсуле открывает выбор сортировки, задачи переставляются по-настоящему. Зажми задачу и потяни — увидишь окно «Переключить на ручную?» или само перетаскивание. Слева — варианты оформления; «реком.» — моя рекомендация.

Что попробовать
  1. Нажми ↑↓ → «По приоритету», потом нажми выбранный вариант ещё раз — порядок развернётся. На кнопке появится точка.
  2. Зажми задачу (полсекунды) и потяни — спросит про ручную сортировку. Согласись и перетащи.
  3. При «Вручную» нажми «+» — новая задача встанет в начало.
  4. Переключи экран на «Входящие» — у него своя сортировка; «Предстоящее» — без «Вручную»; «Хаб» — без кнопки ↑↓, порядок как в «Предстоящем».

Уже решено тобой и не меняется здесь: варианты «по сроку / по приоритету / вручную / по дате создания», стрелка направления, одинаковый срок — по названию, «Без даты» отдельным блоком, «Выполнено» свёрнуто внизу, у каждого списка своя сортировка, новая задача при «Вручную» — в начало, в «Предстоящем» нет «Вручную», в хабе и виджете кнопки нет. Моё предложение для «Предстоящего»: «по времени (как сейчас) / по приоритету / по дате создания». При «По приоритету» внутри одного приоритета — по сроку, затем по названию.

Сортировка запоминается у каждого экрана отдельно — переключай экраны сверху.
