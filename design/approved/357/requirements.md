# ТЗ #357 — Сортировка задач

Решения PM 27.11.2026: 20 вопросов (Issue #357) и выбор в [конструкторе](constructor.html). PM поручил ТЗ, код, проверку и выпуск без промежуточных согласований.

## 1. Где
| Экран | Кнопка ↑↓ | Варианты | Стандарт |
|---|---|---|---|
| Экран списка | да | по сроку, по приоритету, вручную, по дате создания | по сроку ↑ |
| «Входящие» | да | те же | по сроку ↑ |
| «Предстоящее» (порядок внутри дня) | да | по времени, по приоритету, по дате создания | по времени ↑ (как раньше) |
| Хаб, виджет «Главная» и «Все» | нет | порядок «Предстоящего» | — |
| Виджет «Входящие» | нет | порядок «Входящих» | — |
| «Неделя», «Списки», поиск, остальные разделы | нет | — | — |

У каждого списка своя сортировка, она запоминается (настройки на устройстве). «Входящие» и «Предстоящее» — свои.

## 2. Кнопка и окно
- В капсуле: ⠿ · ⚙ · ↑↓ · 🎤 · +. Значок — две стрелки (вверх и вниз). На экранах без задач кнопки нет, настройки остаются.
- Сортировка не стандартная — сиреневая точка на кнопке (цвет «+»).
- Нажатие — шторка снизу «Сортировка»: подпись экрана, варианты со значками; выбранный — фиолетовым с ярлыком направления («↑ сначала ранние»).
  Повторное нажатие на выбранный вариант (или на ярлык) разворачивает порядок. Внизу «Сбросить на стандарт» и «Готово».
- Экран списка теперь с капсулой (как «Входящие»); отдельная плавающая «+» убрана; «+» → «Задача» создаёт задачу в этом списке.

## 3. Порядок
- По сроку: день, весь день раньше времени, время; при одинаковом сроке — по названию. ↓ — сначала поздние.
  Подписи дней: «Просрочено» (красная), «пт 27 ноя · Сегодня», «Завтра», даты; задачи без даты — блок «Без даты» (подпись, всегда открыт; без подписи, если датированных нет).
- По приоритету: сначала высокий (↑ — сначала обычные), внутри — по сроку, затем по названию. Без подписей дней.
- По дате создания: сначала новые (↑ — старые), затем по названию.
- Вручную: порядок, заданный перетаскиванием (хранится в задаче); новая задача — в начало списка.
- «Предстоящее»: по времени — как раньше; ↓ — с вечера к утру; по приоритету — высокий выше, внутри по времени; по дате создания — новые выше.
- Выполненные сегодня — внизу, свёрнутая строка «Выполнено · N ›»; нажатие раскрывает. Только что отмеченная тает на месте.

## 4. Перетаскивание
- Нажал и повёл — задача приподнимается с тенью и переносится; нажал и отпустил — режим выбора, как раньше.
- Сортировка не «Вручную» — окно «Переключить на ручную сортировку?» с галочкой «Больше не спрашивать»; «Переключить» — нынешний порядок
  становится ручным. С отметкой «Больше не спрашивать» — переключается сразу.
- В «Предстоящем» перетаскивания нет; в режиме выбора — тоже.

## 5. Проверки
Юнит-тесты порядка (все варианты и направления, ничьи), хранилища, «новая — в начало»; тесты экрана списка (подписи, «Без даты», «Выполнено»,
окно ручной сортировки), капсулы (кнопка и точка); снимки экрана списка и шторки. На телефоне — чек-лист SO357.
