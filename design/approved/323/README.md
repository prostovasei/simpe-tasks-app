# #323. Окно задачи поверх окна дня — вариант 1 «Остаётся на месте»

Статус — PM 24.11.2026: направление «1 + 2» (окно задачи поверх окна дня + «+» превращается в окно задачи), из трёх вариантов окна дня под окном задачи — **1 «Остаётся на месте»**; «1 делай код».
[Issue](https://github.com/prostovasei/simpe-tasks-app/issues/323) · [живой макет, 3 варианта](variants.html).

## Поведение

- «+» в окне дня: окно новой задачи вырастает из «+» (как окно из плашки виджета) и сжимается в него при закрытии.
- Нажатие на задачу: окно задачи вырастает из её строки (по месту нажатия, на ширину окна дня) и сжимается в неё.
- Окно дня остаётся под окном задачи на том же дне и только темнеет затемнением окна задачи; его затемнение не мигает, при возврате оно уже на месте — без роста и каскада.
- «Назад» под окном задачи закрывает окно задачи, а не окно дня.

## Не меняется

Окно задачи, клавиатура, сохранение, окно дня и его анимации (#314).
