# #269 — две вкладки виджета

20.11.2026. Исполнитель Codex. Макеты на согласовании. [Требования и ограничения](requirements.md) · [Issue #269](https://github.com/prostovasei/simpe-tasks-app/issues/269).

- [«Задачи», выбор вида и «Финансы»](widget-tabs.png). Виджет 320×640 dp. Активная иконка чёрная, вторая серая. Выбор вида открыт повторным нажатием на активные «Задачи».
- [Вкладка «Финансы» крупнее](widget-finance.png). Текущий месяц, график и рейтинги из макета #267, шесть вымышленных счетов.
- [Прокрутка на размере 180×110 dp](widget-compact.png). Последовательные позиции одной вкладки. На узком виджете таблицы расположены друг под другом.
- [Интерактивный HTML](screens.html) · [Исходник](screens.py) · [Рендер](render.js).

Для воспроизведения из корня запустить `python3 design/approved/269/screens.py && node design/approved/269/render.js`. Playwright проверяет переключение вкладок, повторное открытие выбора вида, сохранение вида в прототипе, действие «+», видимость графика и последнего счёта в компактном макете. Проверки на Android относятся к этапу реализации.
