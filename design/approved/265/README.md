17.11.2026. Исполнитель Codex. **На согласовании, код приложения не менялся.** [Issue #265](https://github.com/prostovasei/simpe-tasks-app/issues/265), [ТЗ](requirements.md). База 0.74.0 / PR #264 / build-363.

Последнее уточнение PM заменяет предыдущий вариант «+ 2»: из всплывающих окон убираются «Сегодня / Вчера / Завтра» и количество задач полностью. Слева только дата уменьшенным шрифтом 14 px Bold. Справа вытянутая чёрная кнопка «+» 64×32, размеры взяты из WIDGET_ADD_W/H существующей нижней панели виджета. Нижней кнопки нет; добавление остаётся на выбранный день, в том числе пустой.
