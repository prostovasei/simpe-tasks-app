17.11.2026. Исполнитель Codex. **На согласовании, код приложения не менялся.** [Issue #265](https://github.com/prostovasei/simpe-tasks-app/issues/265), [ТЗ](requirements.md). База 0.74.0 / PR #264 / build-363.

PM попросил уменьшить дату и «Сегодня» примерно до размера количества задач, показывать общее количество вместо «выполнено из всех», оставить у добавления только «+» и перенести его наверх. Проверены одинаковый размер даты и счётчика, порядок «+» перед числом, отсутствие нижней кнопки и демонстрационное действие добавления; PNG просмотрены.
