## Нажатия

По ответам PM: заголовок и **пустая область ниже последней видимой задачи** открывают день; промежутки между строками не включаются. У пустого дня открывается вся область под заголовком. В заполненном дне свободной области может не быть.

Вся колонка времени (включая пустую у задачи без времени) и значок переключают выполнение в обе стороны. Название, оставшаяся ширина строки и эмодзи открывают задачу. Зона выполнения не заходит на название. У будущей проекции повтора вся строка открывает исходную задачу, как сейчас. В Неделе показано только время начала, без конца интервала. Долгие нажатия и жесты сохраняются.

Схема зелёный/синий/жёлтый в `interactions.png` — только пояснение областей, не новое оформление приложения. В HTML нажатие выводит название действия; данные и состояние Android-приложения оно не меняет.

**Допущение, не ответ PM:** на карточку 12 ответа нет; «+N» и мини-календарь сохраняют текущий вид и действия.

## Источники и воспроизведение

Каркас HTML-листов и PNG-рендера — `approved/241/screens.py` + `render.js`. Новые макеты собраны непосредственно из текущей геометрии `WeekCell.kt`, `WidgetWeekRows.kt`, `WeekDays.kt`, `design/tools/gen_widget_week.py` и токенов #255. `screens.py` читает размеры/базовые цвета из `designsystem/tokens`, встраивает Manrope из ресурсов и переводит реальные pathData общих значков в SVG. Предлагаемые оттенки/декор из `PROPOSALS` и `.v01`–`.v10` в приложение ещё не внесены.

```sh
python3 design/approved/259/screens.py
node design/approved/259/render.js
```

Нужны Python 3, Node, Playwright и Chromium (по умолчанию `/usr/bin/chromium`, можно задать `CHROMIUM_PATH`). PNG генерируются из самодостаточного HTML без сетевых ресурсов. Все изображения — HTML-эскизы, **не фактические Android/Roborazzi-снимки**. Manrope — настоящий шрифт приложения; системный Roboto виджета приближён браузерным Arial. Разницу шрифтов, эмодзи, точные hit areas RemoteViews и масштабирование Android надо сверить после реализации. Варианты на этих листах не разрешают менять другие экраны #247.
