## Выбор PM, шаг 1 (27.11.2026)

| Блок | Решение |
|---|---|
| Общий вид | хаб в приложении; финансы → задачи → новости; без подписей; 24 между блоками; привычки — плашки; виджет «Главная» — так же |
| Финансы | счёт узкий, траты широкие; серые карточки; суммы «42k»; счёт — эмодзи + название + сумма; нажатие листает счета по кругу; «Потрачено» — сумма + к прошлому месяцу; перерасход — сумма красная; нажатие на «Потрачено» — окно «Бюджет» |

## Правки PM, шаг 2 (27.11.2026, по скриншоту)

- Карточка счёта: без «остаток на счёте» и без точек.
- «−17% к октябрю» — в одной строке с суммой; карточки ниже.
- Плашки «Просрочено» нет — просроченные в начале списка (красный день справа).
- Подсказок «список листается внутри блока» и «касание по краям…» нет.
- Плашки «Показать все новости» нет — компактная кнопка (варианты в «Шаге 3»).
- Задачи — в самом низу (финансы → новости → задачи).
- Привычки — только иконками.
