# #305. Окно голосового ввода: «Цветной прилив»

Исполнитель — Claude Code, ветка `claude/voice-window-redesign` от main `482fa18`. Версия — 0.84.0. Доработка #95, #299.

## Ответы PM (23.11.2026)

| Вопрос | Ответ |
|---|---|
| Запрос | Окно размера и места окна задачи; «Отмену» убрать — закрытие «Назад»; галочка справа внизу; вместо микрофона — волны на всю ширину; слева одна кнопка ⏸/⏺; других текстов нет |
| Вариант | Раунд 3, № 5 «Цветной прилив» (после 10 вариантов и 5 «нитей») |
| Распознанный текст в окне | Да, остаётся |
| Ошибки | Текстом между кнопками паузы и «Готово» |

## Поведение

- Окно — на месте окна новой задачи: снизу сразу над клавиатурой (запомненная высота, иначе 40 % экрана), по бокам 8 dp, скругление 22 dp, высота 212 dp (как окно задачи без срока). Клавиатура окно не двигает.
- Сверху — распознанный текст (уточняемое слово серым). На паузе — поле для правки; нажатие на текст во время записи останавливает её и открывает клавиатуру (#299).
- Снизу на 58 % высоты — три слоя воды. Во время записи — сиреневый, голубой, фиолетовый; голос поднимает воду и раскачивает волны. На паузе и при ошибке вода серая, опускается и успокаивается за 0,6 с. При выключенных анимациях Android — неподвижна.
- Слева — белая кнопка 50 dp: ⏸ во время записи (останавливает), ⏺ на паузе и после ошибки (продолжить / повторить). Неактивна при «Нет доступа», «Распознавание недоступно», «Нет русского языка».
- Справа — чёрная галочка 50 dp: текст уходит в окно новой задачи. Без текста неактивна.
- Ошибки — между кнопками, одной-двумя строками: «Не расслышал — нажмите ●», «Нет доступа к микрофону · Настройки» (нажатие открывает страницу приложения), «Распознавание недоступно», «Микрофон занят», «Нет интернета для распознавания», «Нет русского языка для распознавания», «Не удалось начать запись». Уже набранный текст при ошибке остаётся.
- Закрытие — «Назад» или затемнение; задача не создаётся. Подписей «Говорите», «Слушаю…», «Нажмите…», кнопок «Отмена»/«Готово»/«Повторить» больше нет.
