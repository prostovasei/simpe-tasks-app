## 2. Как будет

```
ВТ, 24 ноя  Вчера                                1
10:00   ○   Claude                         🔔  💲
СР, 25 ноя  Сегодня  ▬▬▬───────────────  1 из 6
03:00   ✓   Футбол                         🔔  🗂️
10:00   ○   ChatGPT                        🔔  💲
14:00   ○   Оценка Займы                   🔔  💼
16:00
ЧТ, 26 ноя  Завтра                               5
```
- Строка: время (колонка 38 dp) · **8 dp** · кружок 20 dp · **8 dp** · название · колокольчик · эмодзи списка.
- Между строками нет линии; кружки стоят друг под другом ровным столбцом.
- Линии «сейчас» нет ни в приложении, ни в виджете. Прошедшие и выполненные задачи остаются как сейчас (тают по #316).
- Заголовок дня: дата Bold, подпись «Вчера/Сегодня/Завтра», у «Сегодня» — полоса прогресса и «N из M», у других дней — число задач справа. Просрочка — красным, как сейчас.
- Блок «Просрочено · N ⌄ →|» вверху — без изменений.

## 3. Объём

| Где | Что меняется |
|---|---|
| Приложение, «Предстоящее» | Строки без линии, отступы 8 dp, без линии «сейчас»; заголовки дней с прогрессом и счётчиками |
| Виджет «Предстоящее» (обычный и плоский) | Строки без линии, отступы 8 dp, без строки «сейчас» (`widget_row_now*`) |
| Дизайн-система | Строка шкалы `TimelineRow`, заголовок дня; новый токен отступа у кружка |

**Решение PM 25.11.2026 (при команде «Код»):** новый вид без линий — **везде, где была такая линия**: окно дня, «Неделя», хаб и все виджеты со шкалой.

## 4. Оценка

Низкая–средняя, одна итерация: **0.92.1** (после выпуска хаба 0.92.0). Без изменений базы данных. Риск — общая строка шкалы используется в окне дня, «Неделе» и хабе: включать новый вид флагом только для «Предстоящего» и проверить снимки остальных экранов.
