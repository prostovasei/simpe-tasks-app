# #334 — строка задачи: время справа

25.11.2026, Claude Code. Запрос PM: время — в правую часть, кружок выполнения крупнее, эмодзи списка — перед названием,
колокольчик меньше; везде, где есть строка задачи.

## Решения PM

| Дата | Решение |
|---|---|
| 25.11.2026 | Макет 1 — «берём все из рекомендаций»: кружок 18 dp, период справа в две строки, справа «🔔 · время» (время у края), колокольчик 16 dp, эмодзи списка 18 dp перед названием |

| 25.11.2026 | Макет 2: кружок повтора — треугольники; подпись дня 12 sp средний серый, «·» между датой и «Сегодня»; справа у просроченных — день недели. Конструктор со всеми вариантами — **ждёт выбора PM** |
