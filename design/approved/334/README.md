# #334 — строка задачи: время справа

25.11.2026, Claude Code. Запрос PM: время — в правую часть, кружок выполнения крупнее, эмодзи списка — перед названием,
колокольчик меньше; везде, где есть строка задачи.

## Решения PM

|---|---|

| 25.11.2026 | Макет 2: кружок повтора — треугольники; подпись дня 12 sp средний серый, «·» между датой и «Сегодня»; справа у просроченных — день недели. Заголовок «Просрочено» — в том же стиле, число просроченных — вправо; числа задач у «Просрочено» и дней — в стиле подписи дня; полоса прогресса тоньше; значок переноса просроченных — минималистичнее. Конструктор со всеми вариантами |
| 25.11.2026 | **Выбор в конструкторе.** Строка: кружок 18; повтор — треугольники; эмодзи списка перед названием, 16; колокольчик 14; справа «🔔 · время»; период одной строкой «14:00–16:00»; время 13 sp средний. Подпись дня: 12 sp средний серый, «·», «вт». Число задач — как подпись дня; у «Сегодня» полоса и «1 из 6». Полоса 1 dp, заполнение чёрное. «Просрочено»: подпись красная; справа день недели, старше недели — дата «17 ноя»; сворачивание — нажатием на подпись (без ⌄); перенос — тонкая →|. Дальше — конструктор шрифта (**ждёт выбора PM**) |

- [Макет 2](prototype2.html) ([артефакт](https://claude.ai/artifact/BhfjQxfh8eexRm1k4U3nku)): кружок повтора (треугольники / «галочки» / кольцо с ↻),

- [Конструктор](constructor.html) ([артефакт](https://claude.ai/artifact/BtWM6JnijX3dDbyf9k3P7C)): живой список и все переключатели; по умолчанию — решения PM («PM?» — вариант, выбранный по смыслу слов PM: стиль числа, толщина полосы 2 dp, красная подпись «Просрочено», тонкий ⌄, тонкая →|, дата у задач старше недели); «Скопировать выбор» даёт текст для чата.
