# ТЗ #334 — строка задачи, подписи дней и блок «Просрочено» (итог)

25.11.2026. Исполнитель Claude Code. Ветка `claude/row-redesign`. Решения PM — в [README](README.md) (макеты 1–2, два конструктора, галерея экранов).
Код — по команде PM «Код» 25.11.2026; открытые вопросы галереи приняты по предложению (см. §5).

## 1. Где

Везде, где есть список задач со строкой шкалы: приложение — «Предстоящее», окно дня, хаб «Главная», «Входящие», списки, «Без списка»,
«Выполненные», «Не буду делать», корзина; виджеты «Все», «Входящие», «Главная» (Android 12+). Ячейки сетки «Недели» не меняются.

## 2. Строка задачи

| Элемент | Значение |
|---|---|
| Высота | 46 dp |
| Кружок выполнения | 18 dp; повтор — стрелки-треугольники `ic_task_repeat_round` (один рисунок везде) |
| Отступ кружок → эмодзи | 10 dp |
| Эмодзи списка | 16 dp перед названием, отступ до названия 8 dp |
| Название | 14 sp, полужирный (Manrope 600), графит `#2E3036` (тёмная `#D6D6D8`) |
| Высокий приоритет | Название, время и кружок — ярким фиолетовым `#862CE0` (`#C49BF2`), жирность как у обычной |
| Выполненные и прошедшие | «Ещё светлее» `#C4C5C8` (`#46484E`), жирность как у обычной; эмодзи и колокольчик — 45 %; выполненная тает к этому цвету (#316), не зачёркнута |
| Колокольчик | 14 dp, после названия, отступ 8 dp |
| Время | 13 sp средний (500), цвет названия, у правого края; период одной строкой «14:00–16:00»; без времени — пусто |

## 3. Подпись дня и числа

- «вт 25 ноя · Сегодня» одной строкой: 12 sp средним серым (`text-secondary`), день недели строчными, без запятой и нуля; «·» перед «Сегодня/Завтра/Вчера».
- Справа число задач тем же стилем; у «Сегодня» — полоса прогресса 1 dp (заполнение чёрное) и «N из M».
- Окно дня — та же подпись вверху окна.

## 4. Блок «Просрочено»

- Все просроченные задачи — одним блоком без разбивки по дням, старые сверху.
- Подпись «Просрочено» красным 12 sp; нажатие на подпись сворачивает и разворачивает блок (стрелки ⌄ нет); тонкая →| рядом переносит всё на сегодня; число — справа.
- Справа у задачи вместо времени — день недели («вт»); старше недели — дата («17 ноя»). Красным.
- На хабе — та же подпись без сворачивания и переноса.

## 5. Приняты по предложению (вопросы галереи)

- «Входящие» и списки: справа день и время — «сегодня 18:00», «завтра 10:00», дальше «пт 27 ноя» (без времени), прошедшие — как в «Просрочено».
- Крупный системный шрифт: период одной строкой, название короче за счёт многоточия.
- Ячейки сетки «Недели» без изменений; новый вид — в окне дня.

## 6. Не входит

Строки Glance для Android 10–11 (запасной виджет): получили единый блок «Просрочено» и новую подпись дня, сама строка — прежняя.

## 7. Приёмка

| Проверка | Ожидаемый результат |
|---|---|
| «Предстоящее» | Кружок 18, эмодзи перед названием, колокольчик 14, время справа; подписи «пт 16 окт · Сегодня» серым, полоса 1 dp |
| Просроченные | Один блок, справа «вт» / «17 ноя» красным; нажатие на «Просрочено» сворачивает, →| переносит |
