# ТЗ: распознавание уведомлений Яндекс Банка о покупках

Issue [#233](https://github.com/prostovasei/simpe-tasks-app/issues/233). Продолжение финансов [#217](https://github.com/prostovasei/simpe-tasks-app/issues/217):
в бэклоге PM после шаблонов операций — «распознавание банковских уведомлений» (`design/approved/217/requirements.md` §1).
Основа — интервью с PM 12.11.2026, 12 вопросов. Статус: черновик ТЗ, ждёт согласования открытых вопросов (§9). Код не начат.

## 1. Цель

Не вводить покупки по карте Яндекс Банка вручную: приложение замечает уведомление банка о покупке и одним нажатием записывает расход.

## 2. Решения PM (интервью 12.11.2026)

| № | Вопрос | Решение |
|---|---|---|
| 1 | Источник | Уведомления банковского приложения на телефоне. СМС не читаем |
| 2 | Что делать с распознанным | Своё уведомление приложения «−850 ₽» с кнопками «Записать» / «Изменить» / «Пропустить» |
| 3 | Банки | Только Яндекс Банк. Остальные — позже |

| 7 | Место | Не заполняется |
| 8 | «Изменить» | Открывает обычное окно расхода с подставленными суммой, счётом и датой |
| 9 | Нет ответа | Смахнул или не заметил — покупка попадает в список «Не разобрано» в финансах |
| 10 | Дубли | Если сегодня на этом счёте уже есть расход на ту же сумму — пометка «похоже, уже записано»; решает PM |
| 11 | Текст уведомлений | Не хранится: берутся только сумма и время |

## 3. Как это работает

```
Уведомление Яндекс Банка «Покупка 850 ₽ …»
        │  приложение читает (нужен доступ к уведомлениям, даётся один раз)
        ▼
Похоже на покупку? ── нет ──► ничего не делаем
        │ да
        ▼
Наше уведомление: «−850 ₽ · Яндекс»  [Записать] [Изменить] [Пропустить]
        │                 │            │             │
        │                 ▼            ▼             ▼
        │        расход, «Без     окно расхода    ничего не
        │        категории»       с подстановкой   записано
        ▼
Смахнул / не ответил ──► список «Не разобрано» в финансах
```

## 4. Требования

**4.1. Доступ.** В меню шестерёнки финансов — пункт «Уведомления банка»: включить распознавание, дать доступ к уведомлениям
(системный экран Android), выбрать счёт для Яндекс Банка. Без доступа или без счёта распознавание выключено, приложение
это показывает. Выключить можно там же; системный доступ тогда можно отозвать.

**4.2. Распознавание.** Читаются только уведомления приложения Яндекс Банка (по имени пакета). Из текста берутся сумма в рублях
и время уведомления — оно же дата операции. Покупка — только при уверенном совпадении с известным видом текста; неизвестный вид
пропускается (лучше пропустить, чем записать ошибку). Валютные покупки, отмены, возвраты, переводы, пополнения — не распознаются.

**4.3. Наше уведомление.** Заголовок «−850 ₽», текст «Яндекс Банк · <счёт>» (место не показывается), кнопки «Записать», «Изменить»,
«Пропустить». Возможная пометка дубля «похоже, уже записано». Отдельный канал уведомлений «Покупки по карте», без звука и вибрации
(PM не использует вибрацию — см. HANDOFF).

- «Записать» — расход на привязанный счёт, «Без категории», без места, дата — день уведомления; наше уведомление исчезает.
- «Изменить» — открывается приложение с окном нового расхода: сумма, счёт, дата подставлены, остальное как обычно; запись — по «Сохранить».
  Закрыл окно без сохранения — покупка остаётся в «Не разобрано».
- «Пропустить» — ничего не записывается, покупка удаляется из «Не разобрано».

**4.4. «Не разобрано».** Покупки без ответа (уведомление смахнули, телефон перезагрузился, не нажали) — список в финансах.
У каждой — сумма, счёт, дата и те же три действия. Число неразобранных видно в финансах (место — на макете). Список хранится
в базе приложения: только сумма, счёт, время — без текста уведомления.

**4.5. Дубли.** При появлении покупки ищется расход на тот же счёт, ту же сумму, в тот же день, ещё не связанный с другой
распознанной покупкой. Нашёлся — пометка «похоже, уже записано» в уведомлении и в «Не разобрано». Автоматически ничего не пропускается.

**4.6. Повторы.** Одно и то же уведомление банка (обновлённое или показанное повторно) не создаёт вторую покупку.

**4.7. Режим записи примеров (временный).** В настройках «Уведомления банка» — переключатель «Записывать примеры». Пока включён, приложение
сохраняет тексты уведомлений Яндекс Банка (и распознанные, и нет) в отдельный журнал на телефоне с кнопками «Скопировать» и «Очистить».
По умолчанию выключен; журнал очищается при выключении и не попадает в резервную копию. Нужен, чтобы PM прислал примеры новых видов текста.

**4.8. Чего не делаем.** СМС; другие банки; доходы и переводы; подстановку категорий и мест; автоматическую запись без ответа;
хранение текста уведомлений (кроме временного журнала 4.7); отправку чего-либо в интернет.

## 5. Безопасность и данные

- Доступ к уведомлениям — самое чувствительное разрешение: приложение видит все уведомления телефона. Читаем только пакет Яндекс Банка,
  остальные сразу отбрасываем, ничего не сохраняем и не передаём.
- В репозиторий попадают только придуманные примеры текстов с вымышленными суммами, магазинами и картами. Настоящие скриншоты PM в репозиторий не коммитятся.
- Резервная копия финансов включает распознанные операции как обычные расходы; список «Не разобрано» — решить на этапе реализации (§9).

## 7. Этапы (предложение)

1. **Примеры.** PM присылает 3–5 скриншотов уведомлений о покупках; Claude выписывает вымышленные копии и правила распознавания с тестами.
2. **Реализация (0.62.0).** Доступ и настройки, распознавание, наше уведомление с тремя кнопками, «Не разобрано», дубли, журнал примеров.
3. **Проверка на телефоне.** PM неделю пользуется; новые виды текста — через журнал 4.7; правки распознавания.

## 8. Критерии готовности

- Покупка по карте Яндекс Банка за несколько секунд даёт наше уведомление с верной суммой.
- «Записать» создаёт расход на привязанный счёт; «Изменить» открывает окно с подстановкой; «Пропустить» ничего не пишет.
- Смахнутые и пропущенные после перезагрузки покупки — в «Не разобрано».
- Дубль помечается и не пропускается сам.
- Уведомления других приложений не читаются и не сохраняются; текст Яндекс Банка не хранится вне журнала 4.7.
- Тесты распознавания на вымышленных примерах всех известных видов текста; полная проверка и Android CI зелёные.

## 9. Открытые вопросы к PM

1. **Ответы 11 и 12.** Текст не храним (11), но режим записи примеров (12) его временно хранит. Предложение: журнал — только по явному
   включению, только на телефоне, очищается при выключении. Подходит?
2. **Где «Не разобрано».** Предложение: строка над списком операций «Не разобрано: 3» и отдельный экран. Покажу на макете.
3. **Время на ответ.** Наше уведомление висит, пока не ответишь или не смахнёшь. Нужно ли его убирать само через сколько-то часов?
4. **Резервная копия.** Включать ли «Не разобрано» в файл копии? Предложение: нет — это временный список.
5. **Покупка в рассрочку / с кешбэком / в валюте.** Предложение: не распознавать, пока не увидим примеры.
