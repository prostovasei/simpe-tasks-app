# Фильтр недели — виджет и приложение (#243)

Статус: **согласовано PM 14.11.2026** («Только долгое нажатие на виджет и „Настроить“. Делай»). В макете 1.1 предлагалось нажатие на значок «Неделя» — PM выбрал «Настроить» по долгому нажатию на виджет. [Issue #243](https://github.com/prostovasei/simpe-tasks-app/issues/243).

- [screens.html](screens.html): [1. Виджет «Неделя»](screens-1.png) · [2. Страница «Неделя» в приложении](screens-2.png)
- Сборка: `python3 design/approved/243/screens.py` → `node design/approved/243/render.js`. Содержимое — снимки из `app/screenshots` (вымышленные данные).

Решения PM 14.11.2026: три вкладки виджета остаются («Все», «Входящие», «Неделя»); окно «Показывать в виджете» и вкладки отдельных списков убираются;
фильтр только для «Недели», по спискам; несколько списков, режимы «показать выбранные» / «скрыть выбранные»; галочка на папке выбирает все её списки;
пункт «Без списка» (задачи с датой и без списка); «Когда-нибудь» и «Входящие» в фильтре нет; у каждого виджета свой фильтр; у приложения свой, независимый от виджета;
без подсказок и без признака «фильтр включён»; пустая неделя по фильтру — пустые дни.

Правила для реализации (предлагаю): ничего не отмечено — фильтра нет (в любом режиме); «Сбросить» снимает все отметки; папка отмечена, если отмечены все её списки,
и показана с «–», если отмечена часть; старый выбор вида в виджете при обновлении сбрасывается на «Все».
Открытие в виджете: у виджета нет заголовка; решение PM — только долгое нажатие на виджет → «Настроить» (нажатие на значок «Неделя», лист 1.1, отклонено);
в приложении — долгое нажатие на значок «Неделя» в нижней панели (лист 2.1).
