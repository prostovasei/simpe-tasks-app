# #95. Голосовой ввод задачи из виджета

Статус — на согласовании PM. [ТЗ](requirements.md) · [Issue](https://github.com/prostovasei/simpe-tasks-app/issues/95) · [Исходник макетов](screens.html).

- [Панель, вид кнопки](bar-variants.png) — М1 «две чёрные кнопки» или М2 «микрофон светлый», 392 dp.
- [Узкие размеры](bar-narrow.png) — 320 dp; 180 dp в вариантах К1 «вкладки ужимаются» и К2 «без микрофона»; другие вкладки без изменений.
- [Окно распознавания](voice-flow.png) — системный запрос разрешения, «Слушаю», текст по ходу речи, окно задачи с подставленным сроком.
- [Ошибки](voice-errors.png) — «Не расслышал», нет доступа к микрофону, распознавание недоступно.

Размеры панели — SizeTokens виджета, цвета ColorTokens, шрифт Manrope. Окно задачи повторяет снимок `smart_date_light`.
PNG собраны Playwright из `screens.html` (масштаб 2).
