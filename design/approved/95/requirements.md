Рабочие допущения, PM не возразил: автоостановка после паузы, кнопки «Отмена»/«Готово», цель задачи как у «+», сообщения об ошибках — см. ниже.

## 1. Кнопка в виджете

- Только на вкладке «Задачи», справа от «+». На «Финансах», «Здоровье», «Новостях» панель без изменений, вкладки не сдвигаются.
- Широкая панель: «+» 40 × 32 dp, зазор 4 dp, микрофон 40 × 32 dp — вместе 84 dp, как дата с кнопкой обновления справа, вкладки остаются по центру. Вид кнопки — **М1**, две чёрные (выбор PM; М2 отклонён).
- Компактная панель (уже 356 dp): «+» 44 dp и микрофон 40 dp, вкладки 31 dp — помещается от 224 dp. На 180–223 dp — **К2**, микрофон скрыт (выбор PM; К1 отклонён).
- Описание для TalkBack: «Создать задачу голосом».

## 2. Окно распознавания

- Нажатие на микрофон открывает прозрачное окно поверх рабочего стола (как «+»), без запуска всего приложения.
- Первый запуск: системный запрос «Разрешить записывать аудио?». Разрешение `RECORD_AUDIO` нужно только для этой кнопки.
- «Слушаю»: подсказка «Например, „Позвонить маме завтра в 10“», чёрный микрофон, кнопки «Отмена» и неактивная «Готово».
- По ходу речи: распознанный текст жирным, ещё уточняемые слова серым; круг вокруг микрофона меняется с громкостью голоса.
- Конец: распознаватель сам завершает запись после паузы (~2 с) или по «Готово». «Отмена», «Назад» и нажатие на затемнение закрывают окно без задачи.
- Движок — системный `SpeechRecognizer` (обычно Google), язык `ru-RU`, промежуточные результаты включены. Звук и текст приложение не сохраняет и не пишет в журналы.

## 3. Окно задачи

- После распознавания открывается существующее окно «+» с текстом в названии. Разбор даты и времени из названия работает как при наборе: «завтра в 10:00» → чип «Завтра, 10:00».
- Клавиатура закрыта, чтобы окно было видно целиком; нажатие на название открывает её для правки. Сохранение — кнопка ✓.
- Куда попадает задача — как у «+» этого виджета: «Все» — на сегодня, «Входящие» — во входящие, выбранный список — в него. Срок из текста имеет приоритет.
- Проверить разбор на реальных фразах распознавания («в 10 часов», «в 7 вечера», «послезавтра», «в пятницу») и при необходимости расширить `SmartDateParser`.

## 4. Ошибки

| Ситуация | Окно |
|---|---|
| Ничего не распознано, тишина | «Не расслышал», подсказка, «Отмена» / «Повторить» |
| Доступ к микрофону запрещён | «Нужен доступ к микрофону», «Отмена» / «Открыть настройки» (страница приложения) |
| Нет сервиса распознавания, нет сети без офлайн-пакета, язык не поддерживается | «Распознавание недоступно», подсказка про приложение Google и офлайн-распознавание, «Закрыть» / «Повторить» |
| Микрофон занят (звонок, другая запись) | как «Распознавание недоступно», текст «Микрофон занят другим приложением» |

## Ограничения

- Нужен сервис распознавания речи (приложение Google). На телефонах без сервисов Google кнопка покажет «Распознавание недоступно».
- Без интернета — только с офлайн-пакетом русского языка.
- Пока идёт запись, Android показывает зелёный индикатор микрофона.
- Батарея и трафик практически не расходуются: микрофон работает только во время диктовки.
- Долгое нажатие на кнопки виджета Android не поддерживает.

## Приёмка (ручные проверки на телефоне — VI95-1–6)

1. Первый запуск: запрос разрешения, после «Разрешить» сразу начинается запись.
2. Продиктовать «Позвонить маме завтра в 10»: текст появляется по ходу речи, после паузы открывается окно задачи с чипом «Завтра, 10:00»; ✓ сохраняет задачу.
3. «Отмена» в обоих окнах, «Назад» и тап по затемнению — задача не создаётся.
4. Молчать — «Не расслышал» → «Повторить» работает. Запретить микрофон — «Открыть настройки» ведёт на страницу приложения.
5. Режим полёта без офлайн-пакета — «Распознавание недоступно»; с офлайн-пакетом — распознаёт.
6. Микрофон только на вкладке «Задачи»; на 392, 320 и 180 dp кнопки соответствуют выбранным вариантам, вкладки на месте.

## Вне объёма

- Микрофон внутри приложения.
- Платные облачные сервисы распознавания.
- Создание задачи без окна подтверждения.
