## Поведение

- Окно голоса — «Цветной прилив» (#305), запись до ⏸ и 10 с тишины (#308). Каждая фраза, которую распознаватель закончил на паузе, — задача; срок и время разбираются `SmartDateParser`, фраза срока вырезается из названия. Если разбор дат выключен в настройках — название как сказано, без срока.
- Над окном — карточка со списком по дням: заголовок «вт, 24 ноя» (`WidgetDates.bar`), строки — название, время справа, «×». «Без даты» — в конце. Внутри дня — сначала без времени, потом по времени. Список прокручивается, новая задача видна.
- Без срока: у вида «Все» — на сегодня, иначе без даты (как у «+» виджета). Сохранение — во «Входящие», напоминание по умолчанию.
- Нажатие на задачу: запись обрывается (недоговорённая фраза тоже становится задачей), окно задачи вырастает из места окна голоса (анимация роста из плашки, как из виджета). В названии — фраза как сказана, срок подсвечен. ✓ — задача создаётся и уходит из списка; «Назад» — правка не сохраняется, задача остаётся. Возврат — окно голоса на паузе, ⏺ — диктовать дальше. Черновик «+» правка голосовой задачи не трогает.
- «×» — убрать из списка, подсказка «Убрано: … · Отмена».
- Галочка — число задач на ней (кружок цвета приоритета); сохраняет все задачи списка и недоговорённую фразу, окно закрывается, подсказка «Добавлено N задач · Отмена» (отмена удаляет созданные насовсем). Без задач галочка бледная.
- «Назад» / затемнение: без задач — закрыть; с задачами — «Сохранить N задач?»: «Сохранить все» / «Не сохранять».
- Ошибки — как в #305 (между кнопками), список не теряется; сохранение работает без интернета.

## Отличия от прототипа

- Пока открыто окно задачи, список над ним не виден (в прототипе — бледный): окно задачи — отдельный экран со своей анимацией роста из окна голоса.
- Подсказки «Сохранено: …» после сохранения одной задачи нет: задача просто уходит из списка.
