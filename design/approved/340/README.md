## Решения (Claude, по поручению PM — без согласования)

| Вопрос | Решение | Почему |
|---|---|---|
| Строка | Строки, как задачи; под названием точки недели пн–вс; справа «🔥 12» и круг 28 | Единый вид с задачами, неделя видна сразу |
| Сделанная сегодня | Остаётся на месте, круг фиолетовый с ✓ | Список не «прыгает» при отметке |
| Расписание | Каждый день / по дням недели / N раз в неделю | Покрывает частые сценарии TickTick |
| Серия | Дни расписания подряд; для «N в неделю» — недели; сегодня не обрывает | Честная серия без давления до конца дня |
| Карточка | Окно снизу: серия, лучшая, за 30 дней, календарь месяца (отметка прошедших дней), изменить / выше / ниже / архив | Всё о привычке в одном месте |
| Хаб | Плашки сегодняшних привычек в ряд после финансов, нажатие — отметка | Быстрая отметка без перехода |
| Виджет | Раздел «Привычки»: «N из M сегодня» и список с отметкой | Как в приложении |
| Напоминание | Одно на модуль, по умолчанию выкл., 21:00, «осталось N из M» | Проще, чем у каждой привычки; можно расширить |
| Копия | Свой JSON, как у «Здоровья» | Единый подход модулей |
| Не входит | Количественные привычки, напоминание у каждой, «заморозка» серии, годовая карта | Следующие итерации |
