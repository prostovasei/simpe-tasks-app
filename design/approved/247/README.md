Согласовано: #FAFAFA, почти чёрный текст, без фона строк (включая фиолетовый фон высокого приоритета в неделе), тонкие бледные линии. Приоритет сохраняется цветом индикатора. Размеры строк, 2×4, подписи, календарь, интервалы, порядок, значки, клики и панели прежние. Экраны работают в светлом оформлении и при тёмной теме Android.

Изоляция: собственные списки/проекты, предстоящие и неделя. Входящие, поиск, служебные экраны, финансы, настройки, окна задачи и фильтра в эту итерацию не входят; у них прежний дизайн. Дизайн всех остальных экранов #247 остаётся в работе. При смене вкладок адаптер использует отдельные layout id для плоского вида и прежних «Входящих»; повторное применение строк сохраняет их стиль.

HTML-альбом строится из app/screenshots после recordRoborazziDebug; это воспроизведение фактического вида, а не обещание точности сгенерированных эскизов. Каркас листов — approved/241/screens.py. PNG эскизов созданы по скриншотам PM; не являются исходниками Android.

Запуск из корня: `python3 design/approved/247/screens.py`, затем `node design/approved/247/render.js` (Node Playwright и Chromium). Android-снимки: `./gradlew recordRoborazziDebug`.

Плоские XML-строки виджета воспроизводятся `python3 design/tools/gen_widget_task_canvas.py` из прежних разметок, без изменения размеров. Постоянные цвета хранятся в ресурсах, поэтому пакет не раздувается дополнительными действиями RemoteViews.
