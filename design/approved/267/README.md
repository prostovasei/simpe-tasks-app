# #267 — аналитика внутри месяца

19.11.2026. Codex. Выбраны три блока: темп расходов, линия долей с иконками (вариант А) и рейтинг магазинов. На согласовании — их компоновка и детали рейтинга. [Требования](requirements.md) · [Issue #267](https://github.com/prostovasei/simpe-tasks-app/issues/267).

- [Экран месяца](month.png) с тремя блоками на вымышленных суммах.
- [Рейтинг крупнее](places.png). Пять мест по сумме, «Все места» раскрывает остальные, «Без места» отдельно.
- [Операции без указанного места](without-places.png). Пустой рейтинг и общая сумма без места.
- [HTML](screens.html) · [генератор](screens.py) · [рендер](render.js).

Фрагмент будущей вкладки «Аналитика» под переключателем месяца. Manrope и нейтральные цвета из приложения. Категории распознаются по иконкам, доли сравниваются по длине отрезков. Для рейтинга полосы сравнивают суммы с первой строкой. Названия магазинов приведены для примера.

Воспроизведение из корня: `python3 design/approved/267/screens.py && node design/approved/267/render.js`. Сверены суммы и сортировка, раскрытие списка, пустой рейтинг и ширина 320 px. Это проверка макета. Для изменения Android-кода нужна команда «Делай код».
