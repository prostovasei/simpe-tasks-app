# #267 — аналитика внутри месяца

19.11.2026. Codex. Три блока по последнему уточнению PM. Темп расходов со шкалой на целый месяц и пунктирным прогнозом, одинаковые сегментированные полосы для категорий и мест. На согласовании формула и детали отображения. [Требования](requirements.md) · [Issue #267](https://github.com/prostovasei/simpe-tasks-app/issues/267).

- [Экран месяца](month.png) с тремя блоками на вымышленных суммах.
- [Рейтинг крупнее](places.png). Четыре места по сумме, «Другие места» раскрывает остальные. «Без места» остаётся отдельной суммой.
- [Операции без указанного места](without-places.png). Один сегмент 100%, подсказка и общая сумма без места.
- [HTML](screens.html) · [генератор](screens.py) · [рендер](render.js).

Фрагмент будущей вкладки «Аналитика» под переключателем месяца. Manrope и нейтральные цвета из приложения. Категории распознаются по иконкам, доли сравниваются по длине отрезков. Полосы категорий и мест показывают доли от одной и той же общей суммы фактических расходов. В рейтинге позиции связывают отрезки с названиями. Пунктир продолжается от сегодняшней суммы до расчётной суммы на конец месяца. Названия магазинов приведены для примера.

Воспроизведение из корня: `python3 design/approved/267/screens.py && node design/approved/267/render.js`. Сверены суммы, положение точки факта и конца прогноза, прогноз 44 800 ₽, отсутствие прогноза в завершённом месяце, раскрытие списка и читаемость подписей на 320 px. Это проверка макета. Для изменения Android-кода нужна команда «Делай код».
