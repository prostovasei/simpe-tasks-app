# #267 — аналитика внутри месяца

19.11.2026. Codex. Три блока по последнему уточнению PM. Темп расходов со шкалой на целый месяц и пунктирным прогнозом, две таблицы в одной строке, категории слева и места справа. На согласовании формула и детали отображения. [Требования](requirements.md) · [Issue #267](https://github.com/prostovasei/simpe-tasks-app/issues/267).

- [Первый экран «Финансы» целиком](finance-home.png). Счета, выбор месяца и аналитика на общем белом фоне. Блоки контента разделены отступами. Вкладка «Аналитика» выбрана.
- [Аналитика месяца крупнее](month.png) с тремя блоками на вымышленных суммах.
- [Две таблицы крупнее](rankings.png) · [узкий экран 320 px](rankings-narrow.png). В каждой четыре пронумерованных лидера и строка «Остальное».
- [Операции без указанного места](without-places.png). В правой таблице только «Остальное» с полной суммой.
- [HTML](screens.html) · [генератор](screens.py) · [рендер](render.js).

Аналитика расположена под счетами и переключателем месяца. Для оформления использован плоский стиль [«Недели»](../../../app/screenshots/week_light.png), для порядка элементов — [снимок «Финансов»](../../../app/screenshots/finance_analytics_light.png). В обеих таблицах номер, название и сумма. У категорий есть иконки. Расходы без места входят в «Остальное» справа. Знак ₽ указан над каждой колонкой сумм. Пунктир продолжается от сегодняшней суммы до расчётной суммы на конец месяца. Названия магазинов приведены для примера.

Воспроизведение из корня: `python3 design/approved/267/screens.py && node design/approved/267/render.js`. Сверены суммы, положение точки факта и конца прогноза, прогноз 44 800 ₽, отсутствие прогноза в завершённом месяце, сумма строки «Остальное» и расположение таблиц рядом без обрезки на 320 px. Это проверка макета. Для изменения Android-кода нужна команда «Делай код».
