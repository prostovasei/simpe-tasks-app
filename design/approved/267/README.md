# #267 — аналитика внутри месяца

19.11.2026. Codex. Три блока по последнему уточнению PM. Темп расходов со шкалой на целый месяц и пунктирным прогнозом, две таблицы в одной строке, категории слева и места справа. На согласовании формула и детали отображения. [Требования](requirements.md) · [Issue #267](https://github.com/prostovasei/simpe-tasks-app/issues/267).

- [Экран месяца](month.png) с тремя блоками на вымышленных суммах.
- [Две таблицы крупнее](rankings.png) · [узкий экран 320 px](rankings-narrow.png). В каждой четыре лидера и строка «Остальное».
- [Операции без указанного места](without-places.png). Подсказка и общая сумма без места.
- [HTML](screens.html) · [генератор](screens.py) · [рендер](render.js).

Фрагмент будущей вкладки «Аналитика» под переключателем месяца. Manrope и нейтральные цвета из приложения. В обеих таблицах название и сумма. Слева у категорий иконки, справа у мест номера. «Расходы без места» вынесены под таблицы. Пунктир продолжается от сегодняшней суммы до расчётной суммы на конец месяца. Названия магазинов приведены для примера.

Воспроизведение из корня: `python3 design/approved/267/screens.py && node design/approved/267/render.js`. Сверены суммы, положение точки факта и конца прогноза, прогноз 44 800 ₽, отсутствие прогноза в завершённом месяце, сумма строки «Остальное» и расположение таблиц рядом без обрезки на 320 px. Это проверка макета. Для изменения Android-кода нужна команда «Делай код».
