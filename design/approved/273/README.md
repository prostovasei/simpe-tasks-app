# #273 — вкладки приложения и виджета

Макеты согласованы 20.11.2026. Исполнитель Codex. [ТЗ и приёмка](requirements.md) · [Issue #273](https://github.com/prostovasei/simpe-tasks-app/issues/273).

- [Приложение](app.png). Четыре вкладки, иконка по разделу задач, окно выбора и отдельная вкладка «Настройки».
- [Виджет](widget.png). Три вкладки, широкий вид и 180×110 dp. Последний вес и график за месяц, выбор раздела задач, ввод веса и окно обновления поверх рабочего стола.

Уточнение #275 от 21.11.2026. На высоком виджете график занимает свободную высоту, даты стоят прямо над нижней панелью, одиночная точка круглая. Панель следует раскладке этого макета во всех трёх вкладках. [Высокий виджет с одной записью](../../../app/screenshots/widget_health_tall_light.png) · [Компактный виджет с несколькими записями](../../../app/screenshots/widget_health_compact_light.png).

Для воспроизведения из корня репозитория выполнить `python3 design/approved/273/screens.py && node design/approved/273/render.js`. Для рендера нужны Chromium и Playwright. Исходник использует снимки и векторные иконки приложения. Утверждённые PNG хранятся рядом с ТЗ.
