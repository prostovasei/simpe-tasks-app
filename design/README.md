## Новая фича

1. Сделать макет из общих токенов и компонентов, показать PM.
2. Записать выбранный вариант, дату и формулировку решения в Issue/PR; сохранить исходник и утверждённое HTML/PNG-превью в `design/approved/<issue>/`.
   У каждого превью указать источник/вариант; не смешивать одобренные и отвергнутые варианты.
3. После реализации обновить дизайн-систему, её превью и затронутые скриншоты приложения.
4. Дать в PR относительные ссылки на материалы. Ссылка на приватный холст не заменяет доступную копию.

Для воспроизведения макета 57 из корня:
`python3 design/mockups/iteration57.py /tmp/simple-tasks-design57/project`.
Генератор пишет HTML-доски и canvas.json; итоговая доска — Final2.dc.html.
Это воспроизведение исходника, не новый акт согласования PM.
